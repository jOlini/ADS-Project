Como o RBAC decide

O painel autentica em POST /auth/login e recebe um token JWT válido por 30 minutos. Os botões aparecem para todos os perfis de propósito: quem decide é a API. Tente uma ação que o seu perfil não tem e veja o 403 no aviso e nas respostas da API.

Token JWT: payload

O payload é só Base64: qualquer um lê. Por isso leva id, nome, perfil e datas, e nunca senha. Quem garante que ninguém alterou é a assinatura, conferida pela API a cada requisição.
